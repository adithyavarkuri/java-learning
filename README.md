# Java Learning

A structured Java mastery repository containing modernized study chapters and focused runnable examples.

## Repository structure

- `docs/` — book-style learning chapters with theory, examples, labs, interview questions, and revision notes.
- `code/` — focused runnable examples created while learning each topic.

Large portfolio projects are maintained as separate repositories.
